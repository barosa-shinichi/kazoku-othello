# かぞくオセロ（公開版 / kazoku-othello）

日本語で遊べる、スマートフォン対応のオセロアプリです。Web版（ブラウザー）とAndroid版があります。

このリポジトリは公開用です。もともとは家族の写真で遊ぶアプリですが、公開版ではイラストの顔（くま・うさぎ・ねこ・いぬ・ぱんだ・ひよこ）を初期データにしています。アプリ内の「写真をかえる」から、自分の写真に差し替えて遊べます。差し替えた写真と名前は端末内にのみ保存され、どこにも送信されません。

## 起動

`index.html` をブラウザで開くだけで遊べます。外部フォントが取得できない場合は端末のフォントを使います。

「最強AI」を利用する場合は `npm start` を実行し、http://localhost:3000 を開いてください。追加パッケージのインストールは不要です。ファイルを直接開くなど、Web Workerが使えない環境では通常の先読みに切り替わります。

## 機能

- くま・ぱんだ・ねこ・うさぎ・いぬ・ひよこの顔で遊べる「かぞくオセロ」。黒と白の顔を選択でき、同じ顔を選ぶと入れ替わります。
- 石の顔がくるりと変わるアニメーションと、家族の名前入りの応援・勝敗メッセージ
- 写真は `assets/` に保存し、CSSで顔の部分を表示します。
- 「写真をかえる」ボタンから、家族の写真と名前を変更できます。写真を選んだあと、拡大縮小と位置合わせをして丸く切り抜きます。家族の追加（12人まで）と削除（2人まで）もでき、追加した家族はキャラクターの絵文字を選べます。変更した内容は端末内に保存され、最初から入っている写真は「もとにもどす」で戻せます。パソコンとAndroidの設定は別々です。
- コンピューター対戦：やさしい・ふつう・むずかしい・最強AIの4段階。CPUは白を担当します。
- 対戦モードのすぐ上に独立した丸い赤色の「最強AIお助け」ボタンを表示。人間の手番にだけ現れ、対象の家族の名前を添えます。押すと最強AIがその人の一手だけを代わりに打ちます。ふたり対戦でも利用でき、思考中の連打や手動着手は防止します。
- 同じ画面でふたり対戦。対局中も盤面・手番・履歴を保ったままCPUへ交代でき、ふたり対戦にも戻せます。
- 合法手の表示切り替え、直前の一手の表示
- 一手もどす（CPU対戦では前回の自分の手番まで）
- 自動パス、終局判定、得点と勝敗の表示
- 勝利時は勝者の攻撃と同じキャラクターでお祝い（くま：恐竜、ぱんだ：たぬき、ねこ：ハッキング、うさぎ：ねこ、いぬ：黒板と本の先生、ひよこ：お花）。演出はクリック・タップ（キーボードではEnter・Space）で閉じるまで表示されます。
- 対局のやり直しと遊び方ダイアログ

通常の難易度は、ランダム着手・2手探索・4手探索です。最強AIは約3秒の時間内で反復深化・αβ探索・局面のキャッシュを使い、角・着手可能数・外側の石などを評価します。終盤は時間内で可能な限り終局まで読みます。人間に必ず勝つことを保証するものではありません。

思考はWeb Workerで行うため、思考中も交代・難易度変更・一手もどすを操作できます。操作時は古い思考を中断します。盤面・手番・履歴・家族の選択・設定は端末内に自動保存され、次に開くと続きから遊べます。ブラウザーやアプリのデータを消すと保存した対局も消えます。パソコンとAndroidの対局は別々に保存されます。

## Android版

公開版のAPKはサンプルです。アプリIDを `jp.family.kazokuothello.sample` にしてあるので、自分でビルドした本番用アプリとは別のアプリとして入ります。署名鍵はビルド時に自動生成され、リポジトリには含みません。

- インストール用ファイル：`android/releases/kazoku-othello-1.0.0.apk`（約11.2 MB）
- 対応設定：Android 8.0以降。端末のAndroid System WebViewは更新して使用してください。
- [スマホへのインストール手順](android/releases/インストール手順.md)
- 写真・ゲーム・AIをアプリに同梱し、ネット接続なしで遊べます。
- パソコン版は上記の方法で引き続き利用できます。

### APKを作り直す場合

`android/build-apk.cmd` をダブルクリックするか、PowerShellで `./android/build.ps1` を実行します。開発ツールがない場合は `./android/build.ps1 -Setup` で指定バージョンを取得し、チェックサムを確認してからビルドします。ツールは `%LOCALAPPDATA%\family-othello-tools` に置きます（一時フォルダーはWindowsの掃除で消えるため）。

`.android-signing/` は更新用の署名鍵とパスワードです。両方を安全な場所にバックアップし、配布するのはAPKだけにしてください。同じアプリとして更新するには同じ署名鍵が必要です。次の配布版では `android/AndroidManifest.xml` のバージョンと `android/build.ps1`・ブラウザーテストのAPK名を更新します。

## 検証

`npm test` でルール、盤面境界、パスと終局、AI着手、最強AIの終盤の全探索との一致、保存データの検証を実行できます。

`npm start` でパソコン版を起動し、Playwright・JSZipとMicrosoft Edgeを利用できる環境で `node --test android/verify-browser.test.cjs` を実行すると、APK内のファイルを使ったオフライン動作・AIワーカー・保存と再開・スマホ幅の表示、およびパソコン版を確認できます。既存の依存ライブラリーを使う場合は `FAMILY_TEST_DEPENDENCIES` にその `node_modules` フォルダーを指定します。
